# Interactive Dashboard Deliverable

The project included a dark-themed interactive dashboard designed to make the notebook's results accessible to technical and non-technical reviewers.

## Dashboard sections

- dataset profile and class imbalance;
- material and assay representation;
- numeric distributions and missingness;
- toxicity rate by material;
- classification and regression model comparison;
- precision–recall threshold trade-offs;
- study-grouped validation results;
- limitations and recommended next experiments.

The dashboard was synchronized with the final notebook: labels were corrected, duplicate tables were removed, plots were made interactive, and explanatory text distinguished observed associations from predictive claims.
